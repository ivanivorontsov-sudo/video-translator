# 🌐 Переводчик видео (Chrome/Edge, MV3)

Это расширение переводит любое видео или аудио в браузере. Режим выбирается в меню: **субтитры**, **закадровый голос** (оригинал приглушается) или **оба сразу**.

## Как это работает
1. **Готовые субтитры сайта.** Если они есть, расширение берёт их: YouTube (в том числе автосубтитры), элементы `<track>` и `textTracks` у любых `<video>`/`<audio>`. Так быстрее всего (задержка ≈0,1–1 с) и точнее всего.
2. **Иначе — звук вкладки.** Звук захватывается через `chrome.tabCapture` и обрабатывается в offscreen-документе. Вы продолжаете его слышать через GainNode, на котором и делается приглушение. Дальше идёт распознавание и перевод.
   - **Google Web Speech** (бесплатно, по умолчанию): `SpeechRecognition.start(audioTrack)`, Chrome 135+. Промежуточные результаты тоже переводятся, раз в 1,2 с, чтобы субтитры появлялись раньше. Фраза закрывается после 1,5 с тишины.
   - **Остальные движки** работают кусками: энергетический VAD режет поток по паузам (не меньше 0,7 с речи и 0,45 с тишины, не больше 8 с). Готовые куски уходят в выбранный STT.
3. **Перевод:** Google (бесплатно), DeepL, OpenAI GPT с контекстом предыдущей фразы, Yandex, Microsoft, встроенный Translator API Chrome или Opus-MT локально. Если движок не сработал, расширение по очереди пробует Google, затем Chrome, затем Opus-MT. Такой перевод помечается значком ⚠.
4. **Озвучка:** `chrome.tts` с выбором голоса и скорости. Пока звучит перевод, оригинал приглушается. Если фразы копятся в очереди, речь ускоряется (×1,15 или ×1,35), чтобы не отставать от видео.
5. **Задержка:** оверлей показывает её честно, от начала фразы до вывода перевода. Черновые результаты помечены.

## Движки распознавания
| Движок | Ключ | Цензура на стороне сервиса |
|---|---|---|
| Google Web Speech (по умолчанию) | нет | — (работает наша маска) |
| Whisper локально (transformers.js; tiny, base, small или large-v3-turbo; WebGPU или WASM) | нет, офлайн | — |
| OpenAI gpt-4o-transcribe / whisper-1 | да | — |
| Groq whisper-large-v3-turbo | да | — |
| ElevenLabs Scribe | да | — |
| Deepgram Nova-3 | да | `profanity_filter` |
| AssemblyAI | да | `filter_profanity` |
| Yandex SpeechKit | да | `profanityFilter` |
| Microsoft Azure Speech | да | `profanity=masked` |

Для Microsoft Translator передаётся `profanityAction=Marked`. Если какой-то движок цензуру не поддерживает, работает наша маска мата (русские и английские корни). Переключатель «Цензура мата: вкл/выкл» есть в меню.

## Приватность
Телеметрии нет. Ключи хранятся только в `chrome.storage.local` и отправляются только выбранному сервису. Локальные модели скачиваются с huggingface.co один раз, при первом использовании, и дальше лежат в кэше браузера.

## Установка
1. Откройте `chrome://extensions` и включите «Режим разработчика».
2. Нажмите «Загрузить распакованное» и выберите папку.
3. Окно расширения открывается сочетанием Alt+T.

## Ограничения
- DRM-видео (Netflix и подобные): захват звука может давать тишину. Обходов нет и не будет.
- Захват звука требует клика по значку расширения на нужной вкладке. Так устроен activeTab у Chrome.
- Качество голоса зависит от голосов в системе. В Chrome есть облачные голоса Google, в Edge — нейронные голоса Microsoft.
- Субтитры YouTube расширение берёт из уже отрисованного плеера. Если YouTube их не отдаёт, включается перевод звука.

## Исследование и выбор библиотек (кратко)
- **Похожие продукты.** Яндекс Браузер и VOT (vot.js) делают закадровый перевод на серверах Яндекса. У API нет публичной лицензии, поэтому мы его не используем. Из VOT взяли идею приглушения оригинала и отдельной громкости. Immersive Translate и Language Reactor берут готовые субтитры YouTube; оттуда идея «сначала субтитры». Trancy склеивает субтитры в предложения перед переводом; у нас это склейка «скользящего окна» автосубтитров. Rask и ElevenLabs Dubbing дают офлайн-дубляж высокого качества, но платный и не в реальном времени.
- **WER для русского.** ElevenLabs Scribe и GigaAM лидируют. Deepgram Nova хорош на чистой речи. Whisper large-v3-turbo даёт примерно 4–10%, Yandex SpeechKit — около 5%. Поэтому облачные движки сделаны опцией, а бесплатный дефолт — Google.
- **@huggingface/transformers 3.8** (Apache-2.0): Whisper и Opus-MT в браузере с WebGPU или WASM. Встроен; модели скачиваются по требованию.
- **onnxruntime-web** (MIT): приходит вместе с transformers.js, wasm лежит внутри расширения (CSP не позволяет грузить его с CDN).
- **Не взяты:**
  - @ricky0123/vad-web / Silero VAD (ISC/MIT): ещё ~2 МБ модели и отдельный ort. Для нарезки по паузам хватает адаптивного энергетического VAD.
  - vosk-browser (Apache): для русского заметно хуже Whisper и Google.
  - Bergamot (MPL): нет русско-английской пары нужного качества, тяжёлая сборка.
  - Piper и sherpa-onnx TTS: десятки МБ на голос; `chrome.tts` уже даёт нейронные облачные голоса.
  - vtt.js: нативный `textTracks` уже разбирает VTT.
